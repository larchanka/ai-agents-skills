# Коллекция инженерных навыков и ИИ-агентов

Репозиторий представляет собой готовую библиотеку настроек, системных ролей (агентов), промптов и сценариев работы (навыков) для интеграции ИИ-ассистентов (Claude Code, Cursor, OpenCode и др.) в рабочий процесс веб-разработки. 

---

## Архитектура проекта

Проект разделен на три основных уровня инструментов и вспомогательные справочные материалы:

```
├── skills/          # Навыки (алгоритмы работы — «Как делать?»)
├── agents/          # Агенты (роли и персоны ИИ — «Кто делает?»)
├── prompts/         # Промпты (сценарии оркестрации — «Когда делать?»)
├── references/      # Справочники (чек-листы стандартов качества кода)
├── docs/            # Документация и обучающие упражнения
├── CLAUDE.md        # Инструкции для Claude CLI / Claude Code
└── GEMINI.md        # Инструкции для Gemini CLI / Antigravity
```

### Подробное описание директорий:

1. **Навыки (`/skills/`)** — специализированные каталоги, содержащие файлы `SKILL.md` и автоматизирующие скрипты. Они описывают пошаговые процессы для ИИ-агента:
   - `spec-driven-development` — проектирование спецификации перед написанием кода.
   - `frontend-ui-engineering` — создание интерфейсов промышленного качества.
   - `debugging-and-error-recovery` — воспроизведение багов через тесты и их исправление.
   - `ci-cd-and-automation` — настройка CI/CD конвейеров.
   - `code-review-and-quality` — проведение многофакторного аудита кода.
   - `mr-review` — контекстно-зависимый разбор запросов на слияние (GitLab + Jira + Confluence).
   - `gmail-triage` — автономная сортировка писем и подготовка черновиков.
   - `humanizer` — удаление признаков ИИ-текста, улучшение стиля и выразительности.
   - `dnote` — управление личными заметками и базой знаний через командную строку.

2. **Агенты (`/agents/`)** — конфигурационные файлы специализированных ролей ИИ с различной глубиной мышления (`thinking`) и системными промптами:
   - `worker.md` — исполнитель задач и разработчик.
   - `reviewer.md` — рецензент кода.
   - `researcher.md` — агент для глубокого сбора информации и интернет-исследований.
   - `scout.md` — агент для быстрого анализа локальной кодовой базы.
   - `oracle.md` — консультант для решения сложных спорных архитектурных вопросов.
   - `context-builder.md` — сборщик контекста для передачи другим агентам в цепочке.

3. **Оркестрация и промпты (`/prompts/`)** — шаблоны сценариев для совместной работы нескольких агентов:
   - `review-loop.md` — цикл доработки кода (разработчик исправляет замечания ревьюера до полного одобрения).
   - `parallel-review.md` — параллельный запуск нескольких ревьюеров разного профиля с последующим слиянием отчетов.
   - `parallel-research.md` — параллельное исследование с разделением фокуса между исследователями сети и кодовой базы.

4. **Справочники (`/references/`)** — чек-листы и соглашения, используемые для контроля результатов:
   - `git-conventions.md` — правила ветвления, Conventional Commits и пул-реквестов.
   - `performance-checklist.md` — метрики Core Web Vitals и оптимизация производительности.
   - `security-checklist.md` — чеклист безопасности и защиты веб-приложений (OWASP).

5. **Обучение (`/docs/`)** — стартовые материалы:
   - `setup-guide.md` — пошаговое руководство по импорту навыков и агентов в Claude Code, Cursor и веб-интерфейс.
   - `mcp-setup.md` — инструкция по настройке протокола MCP (Model Context Protocol) для подключения баз данных и внешних API к ИИ.
   - `exercises.md` — 3 практических задания для тренировки навыков работы в связке с ИИ.

---

## Методология работы: Выполнение, управляемое навыками

Ключевой принцип работы этого репозитория — **модель выполнения, управляемая навыками (Skill-Driven Execution)**:

1. **ИИ не импровизирует**: При возникновении любой задачи (например, «напиши авторизацию») ИИ-ассистент обязан сначала найти подходящий навык в папке `/skills/` и строго следовать его шагам.
2. **Ты-форма**: Обращение к ИИ-агенту во всех промптах и инструкциях всегда формулируется в **единственном числе** (на «ты»). Это помогает ИИ точнее ассоциировать себя с выполняемой ролью.

## Быстрый старт

1. Изучи [Руководство по настройке](./docs/setup-guide.md), чтобы интегрировать эти навыки в свой рабочий инструмент (Claude Code, Cursor или любой другой).
2. Настрой [Model Context Protocol (MCP)](./docs/mcp-setup.md) для предоставления ИИ доступа к базе данных или репозиториям.
3. Выполни [Практические упражнения](./docs/exercises.md), чтобы увидеть работу агентов вживую на реальных примерах.
