# Управление заметками через Dnote CLI

Если `dnote` не установлен, используй следующую команду для его установки:

```bash
brew install dnote
```

## Обзор

Dnote — это инструмент управления личными знаниями, который позволяет быстро фиксировать и извлекать информацию через командную строку. Этот навык содержит инструкции по использованию Dnote CLI для эффективного ведения заметок и их организации.

## Основные команды

### Добавление заметки

Добавь новую заметку в конкретную книгу. Если содержимое не передано через флаги, откроется настроенный по умолчанию текстовый редактор.

**Псевдонимы (Aliases):** `a`, `n`, `new`

```bash
# Базовое использование (открывает редактор)
dnote add <book>

# Добавление содержимого напрямую
dnote add <book> -c "содержимое твоей заметки"

# Перенаправление вывода из другой команды
echo "какие-то данные" | dnote add <book>
```

### Просмотр заметок

Выведи список книг, заметки внутри конкретной книги или содержимое отдельной заметки.

**Псевдоним (Alias):** `v`

```bash
# Показать список всех книг
dnote view

# Показать заметки в конкретной книге
dnote view <book>

# Показать конкретную заметку по ее индексу в книге
dnote view <book> <index>

# Вывести только содержимое заметки (полезно для скриптов)
dnote view <book> <index> --content-only
```

### Редактирование заметки или книги

Измени существующие заметки или переименуй книги.

**Псевдоним (Alias):** `e`

```bash
# Редактировать заметку по ID (открывает редактор)
dnote edit <note-id>

# Обновить содержимое заметки напрямую
dnote edit <note-id> -c "новое содержимое"

# Переместить заметку в другую книгу
dnote edit <note-id> -b <new-book-name>

# Переименовать книгу
dnote edit <old-book-name> -n <new-book-name>
```

### Удаление заметки или книги

Удали конкретную заметку или целую книгу.

**Псевдонимы (Aliases):** `rm`, `d`, `delete`

```bash
# Удалить заметку по ID
dnote remove <note-id>

# Удалить книгу целиком
dnote remove <book>

# Удалить без запроса подтверждения
dnote remove <note-id> -y
```

### Поиск заметок

Выполни полнотекстовый поиск по всем заметкам или внутри конкретной книги.

**Псевдоним (Alias):** `f`

```bash
# Искать по всем заметкам
dnote find "ключевые слова"

# Искать внутри конкретной книги
dnote find "ключевые слова" -b <book>
```

## Команды синхронизации

### Синхронизация

Синхронизируй локальные заметки с сервером Dnote.

**Псевдоним (Alias):** `s`

```bash
# Инкрементальная синхронизация
dnote sync

# Полная синхронизация
dnote sync -f
```

### Аутентификация

Управляй подключением к серверу Dnote.

```bash
# Вход (интерактивный)
dnote login

# Вход (неинтерактивный)
dnote login -u <email> -p <password> --apiEndpoint <url>

# Выход
dnote logout
```

## Глобальные флаги

Следующий флаг можно использовать с любой командой для переопределения стандартного пути к базе данных:

- `--dbPath`: Укажи кастомный путь к базе данных Dnote (например, `dnote --dbPath /path/to/db view`).

## Лучшие практики

1. **Используй псевдонимы (aliases)**: Ускорь свой рабочий процесс, используя короткие псевдонимы вроде `a` для `add` и `v` для `view`.
2. **Организация по книгам**: Группируй связанные заметки в «книги» (например, `git`, `python`, `docker`) для более удобного поиска.
3. **Перенаправление вывода**: Направляй вывод консольных команд напрямую в Dnote, чтобы сохранять полезные сниппеты (например, `curl ifconfig.me | dnote add network`).
4. **Неинтерактивное удаление**: Используй флаг `-y` в скриптах или когда полностью уверен в удалении, чтобы пропустить подтверждение.
5. **Режим только содержимого**: Используй флаг `--content-only`, когда тебе нужно извлечь чистый текст заметки для использования в других командах.

## Проверка

- [ ] Выполнение команд возвращает ожидаемый результат (вывод списков, просмотр, поиск).
- [ ] Заметки корректно добавляются/обновляются в локальной базе данных.
- [ ] Синхронизация завершается без ошибок (при наличии авторизации).
- [ ] Переименование книг и перемещение заметок корректно отражаются в `dnote view`.
